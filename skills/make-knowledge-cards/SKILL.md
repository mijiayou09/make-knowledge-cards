# 知识卡片生成

把一篇文章或一个本地 Markdown / TXT 文件，转换成一小组可复习的知识卡片。

## 输入范围

支持：

- 用户直接粘贴在对话里的正文。
- 用户指定的本地 `.md` / `.txt` 文件。优先按 UTF-8 读取；出现乱码时再用 GB18030 重试一次。

不支持——遇到时直接说明并给出替代方案，不要勉强尝试：

- 网页抓取或 URL：请用户把正文粘贴进来。
- PDF：请用户先转成文本/Markdown，或直接粘贴正文。
- Anki 或任何牌组、间隔重复格式的导出。
- 图形界面或应用输出：卡片以 Markdown 回复，用户明确要求时才写入文件。

一次处理一个来源。用户给了多个文件时，先确认是合并成一套卡片还是逐个处理。

## 输出格式

默认 5–8 张卡片，语言与原文一致，用 Markdown 直接回复：

### 卡片 N：<一句判断，而不是话题标签>
**核心知识**：一句话，最该记住的是什么
**简明解释**：2–4 句大白话，说清是什么、为什么、怎么起作用
**例子 / 自测**：原文里的例子；原文没有例子时，改成一个自测问题

英文原文时字段名换成 Title / Core idea / Explanation / Example or self-test question。

标题要写成判断或结论，不要写成话题名：

- 好：`间隔重复在“快要忘记时”复习，才最省时间`
- 差：`关于间隔重复`

只输出卡片和结尾一行说明，不要附加用户没有要求的总结、词汇表或延伸阅读。

## 什么值得做成卡片

按承重程度挑选，优先保留“读者不知道就会吃亏”的内容：

1. 全文的中心论点或结论。
2. 后文依赖的关键概念、定义。
3. 因果机制：为什么会这样、它怎么起作用。
4. 判断标准、决策规则、阈值、步骤等能改变读者行为的信息。
5. 数字、比例、时间点，且数字本身就是信息量所在。
6. 原文专门澄清的常见误解。

以下内容不单独成卡：背景铺垫、过渡句、作者的个人感慨、与主题无关的细节、换个说法重复的观点、有趣但不承重的信息。

## 一张卡片只讲一个知识点

- 一个候选点里含两个能独立理解的想法时，拆成两张。
- 同一观点换了说法，只保留一张。
- 同一原则的正反面（“该做什么”和“不该做什么”）算同一个知识点，合并成一张。
- 某个点必须依附另一个点才讲得通时，合并成一张，不要留“半张卡”。
- 自检：这张卡只回答一个问题吗？能不能用一句话做标题？

标题一律写成判断句。原文用术语命名的（例如“确认偏误”），标题写结论（“确认偏误让人只寻找支持自己的证据”），术语名放在解释里。

解释只写知识本身，不要写“这张卡与上一张互补”这类元评论。

## 不能编造

- 卡片里的每一项都必须在原文中有依据。
- 不补充原文没有的事实、数字、人名、日期、原因、例子，即使你确定它是对的。
- 不要用自己的背景知识补全机制：原文只说“睡满一个完整周期才包含慢波睡眠”，就不要补充“慢波睡眠出现在周期的后段”。
- 自测问题可以重新组织措辞，但答案必须能在原文中找到。
- 原文没有例子时不要自己编例子，改为写自测问题。
- 原文含糊或前后矛盾时，如实标注（例如“原文未说明原因”），不要替它补全。

## 数量

- 目标 5–8 张：先取最承重的，再往下补。
- 原文能支撑 8 个以上独立要点时，取最承重的 8 张，并用一句话说明略去了哪些主题，用户要求时可再补。
- 各要点价值相当（清单、术语表一类文章）时，不要凭主观挑“最重要的”：按原文顺序保留前 8 条，结尾列出被略去的条目名。
- 有解释、机制或可操作信息的独立要点不足 5 个时，按实际数量出卡，并说明“原文只支持 N 个知识点”。不要用复述、废话或琐碎细节凑数。
- 原文只有孤立事实（一条条通知、数据，没有解释也没有可迁移的判断）时，无论几条都不要出卡片：说明素材不足，并列出补充哪类内容（原因、机制、影响）后可以出卡。

## 回复前自检

1. 每张卡只讲一个点，卡片之间没有重复。
2. 每条内容都能在原文中找到出处，没有新增信息。
3. 抽掉任何一张，读者都会少知道一件承重的事。
4. 数量是 5–8 张，或差异有明确理由。
5. 输出语言与原文一致。

## 结尾

卡片之后用一行交代：来源（文件名或“粘贴文本”）、卡片数，以及必要说明（略去的主题、原文信息不足等）。

## 示例

原文片段：

> 很多人以为复习次数越多记得越牢，其实关键在复习时机。记忆在刚学完时下降最快，随后趋缓；在“快要忘记但还没忘记”的时刻复习，能显著延长下次复习的间隔，这就是间隔重复。如果每次都等到完全忘光再学，等于重新学习，时间成本更高。

卡片：

### 卡片 1：决定记忆效果的不是复习次数，而是复习时机
**核心知识**：在“快要忘记但还没忘记”时复习，记忆保持得最久。
**简明解释**：遗忘速度在刚学完时最快，之后逐渐变慢。在遗忘最快的这段区间复习，能用最少的次数把记忆维持最久；等完全忘光再学，等于重新学习。
**例子 / 自测**：原文认为“复习次数越多记得越牢”错在哪里？
